# 🎣 Phishing Awareness Example

## Scenario

You receive an email from “IT Support” saying your password will expire today.  
It asks you to click a link to reset immediately.

## Red Flags

- Urgent language creating pressure  
- Link does not match official domain  
- Unexpected request for credentials  

## Recommended Action

- Do not click the link  
- Verify directly with IT through official channels  
- Report the email if possible  

## Key Message

Pause. Verify. Don’t click.

---

This example demonstrates how small behavioral cues can prevent security incidents.
